# CMC Math 126: Randomized Algorithms for Data Science

The Spring 2027 course website is [math126.rtealwitter.com](https://math126.rtealwitter.com).


Classes meet Mondays and Wednesdays, 2:45–4:00pm in Robert Day 126.
Office hours are Tuesdays, 1:00–4:00pm in Adams 213.

## Layout

- `index.qmd`, `syllabus.qmd`, and `_quarto.yml` define the course website.
- `_variables.yml` holds the semester, meeting details, and course-service links.
- `topics/NN_name/reading.qmd` contains a reading, with its figures in `images/`.
- `topics/NN_name/problems/` contains the related TeX handouts, PDFs, figures,
  and starter code. Original problem numbers are preserved.
- `problems/common/` supplies shared handout formatting, and
  `problems/manifest.json` records deadlines, paths, and Colab provenance.
- `slides/`, `project/`, and `grades/` retain their separate purposes.
- `archive/` preserves the original Colab notebooks and superseded readings.
  It is excluded from the generated website.
- `tools/` contains import, compilation, and validation scripts.
- `docs/` is generated by Quarto and published by GitHub Pages from `main`.

The layout follows `datamining2026fall`. The first fourteen topics follow the
course schedule; the remaining topics preserve supplementary readings.
Historical `notes/*.html` URLs redirect to the reorganized readings.

## Build and publish

On Hopper, run rendering and PDF compilation through Slurm:

```bash
tools/run_compute.sh handouts bash tools/compile_problem_pdfs.sh
python3 tools/check_course.py
tools/run_compute.sh site quarto render
git add -A
git diff --cached --stat
git commit -m "Describe the course update"
git push origin main
```

For an ordinary workstation, run `bash tools/compile_problem_pdfs.sh` and
`quarto render` directly. The tools require Python 3, Pandoc, Quarto, and
pdfLaTeX. See [problems/README.md](problems/README.md) before reimporting notebooks.

Copied from [RADS 2026](https://github.com/rtealwitter/rads2026), preserving
its Git history and course materials. The Discord and Gradescope links still
point to the original course services; edit `_variables.yml` when new ones
are available.
