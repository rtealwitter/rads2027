# CMC Math 126: Randomized Algorithms for Data Science

This is the website source for Math 126 offered in Spring 2027. The website is available at [rads2027.rtealwitter.com/](https://rads2027.rtealwitter.com/).


Copied from [RADS 2026](https://github.com/rtealwitter/rads2026), preserving the course materials and Git history. The schedule, class logistics, external course links, and assignment deadlines are carried over from 2026 and need review before the 2027 offering.

To rebuild the website, run `quarto render`. GitHub Pages publishes the `docs/` directory on `main`. The custom domain is declared in `CNAME` and copied into `docs/` by Quarto.
