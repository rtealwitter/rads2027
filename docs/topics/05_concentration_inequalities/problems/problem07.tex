In this problem, we will derive the density function of the normal distribution from the example of a dartboard. Let \(f: \mathbb{R}^d \to [0,1]\) be a probability density function that describes the probability a dart lands at the point \((x,y)\). We want our probability density function \(f\) to have two properties:

\begin{itemize}
\item
  \textbf{Radial Symmetry:} The probability that a dart lands at a point depends only on the distance between the point and the origin.
\item
  \textbf{Independence:} Coordinates are independent e.g., knowing the \(x\)-coordinate does not give us information about the \(y\)-coordinate.
\end{itemize}

From the radial symmetry property, we can conclude that \begin{align*}
f(x,y) = f(r) = f(\sqrt{x^2 + y^2})
\end{align*} where \(r=\sqrt{x^2+y^2}\) is the distance between the origin and \((x,y)\).

From the independence property, we can conclude that \(f(x,y) = g(x) h(y)\) for some functions \(g\) and \(h\). Further, the radial symmetry property tells us that \(f(x,y) = f(y,x) = g(y) h(x)\) so \(g\) and \(h\) must be the same function. That is, \begin{align*}
f(x,y) = g(x) g(y).
\end{align*}

\subsection*{Part B}\label{part-b}}

Define the function \(h(x) = f(\sqrt{x})\). In particular, \begin{align*}
f(\sqrt{x^2 + y^2}) = f(x) f(y) \Leftrightarrow
h(x^2 + y^2) = h(x^2) h(y^2).
\end{align*} Use this property to show that \begin{align*}
h(x_1 + x_2 + \ldots + x_n) = h(x_1) h(x_2) \cdot \ldots \cdot h(x_n).
\end{align*} Then prove that \(h(n) = h(1)^n\).

Without loss of generality, let \(h(1) = b\).
